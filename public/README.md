# public/

Web root — the only folder exposed to the internet.

## Structure

```
public/
└── css/
    └── app.css    # Compiled Tailwind CSS (generated by npm run build)
```

## Notes

- All HTTP requests go through this directory
- PHP files here should be minimal entry points that load from `app/` and `views/`
- Compiled assets are output here (gitignored)
